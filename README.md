**📊 Sentiment Stability Across News & Social Engagement**

**🔎 Overview**

This project compares sentiment patterns in financial news and Twitter engagement to evaluate which industries show the most stable and predictable sentiment. It focuses on Tech, Retail, Healthcare, and Finance using data from 2019–2022.

**🛠 Methods**

- SQL (AWS DB1) for data extraction
- R (tidyverse, tidytext) for cleaning and sentiment scoring
- Monthly aggregation for trend clarity
- ETS forecasting to measure predictability
- ggplot2 for visualizations

**📈 Key Insights**
- News sentiment is stable with narrow forecast intervals.
- Tweet sentiment is volatile, driven by public reactions and events.
- Tech & Finance show consistent news tone but highly reactive tweets.
- Combining both channels reveals deeper sentiment behavior.

**🏁 Conclusion**

News provides predictable long‑term sentiment, while tweets capture fast‑moving public emotion. Together, they offer a fuller view of industry sentiment dynamics.
